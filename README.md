# Хаб

Особистий трекер самоконтролю: **задачі**, **сон** і **фотощоденник їжі** в одному
застосунку. Одна сторінка без бекенду — працює у браузері на комп'ютері й на
телефоні, у тому числі офлайн, і встановлюється як окремий застосунок.

Молодший брат [«Щоденника»](https://github.com/Cqessaw/shchodennykk): та сама
архітектура (звичайні HTML/CSS/JS, PWA, дані на пристрої) і ті самі теми
Latte та Mocha.

## Що вміє

### Задачі

- Одноразові та повторювані — щодня або в конкретні дні тижня
  (наприклад «зал» тільки Пн/Ср/Пт).
- Щоденна відмітка одним дотиком, гортання по днях назад і вперед.
- **Streak** на кожну повторювану задачу: скільки *планових* днів поспіль
  виконано. Невиконаний сьогоднішній день стрік не рве — він ще попереду,
  а дні, коли задача не в плані, пропускаються.
- Теплокарта за 12 тижнів і список виконаного по датах.
- Порядок задач міняється стрілками, зайву можна сховати без втрати історії.

### Сон

- Дві кнопки — «Ліг спати» і «Прокинувся», час підставляється сам.
- Тривалість рахується автоматично, якість — п'ять зірок.
- Графік по днях (2 тижні / місяць) або по тижнях, із лінією норми.
- **Помічник**: нагадує, коли час лягати, і попереджає, якщо останні ночі
  стабільно коротші за норму. З дозволом на сповіщення нагадування приходить
  системним повідомленням.

### Їжа

- Кнопка **«Сфотографувати їжу»** відкриває камеру одразу — знімок потрапляє
  у стрічку без зайвих кроків. Можна й вибрати кілька фото з галереї.
- Під кожним фото дві кнопки: **Солодке** / **Звичайне**.
- Лічильник **днів без солодкого** з рекордом, статистика по тижнях.
- Галерея-стрічка по датах — візуальний щоденник їжі, який закриває проблему
  «забуваю, що їв».

### Огляд

Одна сторінка згори: скільки задач лишилось на сьогодні, активні стріки,
графік сну за тиждень, стрік без солодкого і мініатюри останніх фото.
Попередження помічника з'являються тут же.

## Встановити на телефон

1. Відкрити сторінку в Chrome (Android) або Safari (iOS).
2. Android: меню ⋮ → **Встановити застосунок**.
   iOS: кнопка «Поділитися» → **На екран «Домівка»**.
3. Далі відкривається з іконки як звичайний застосунок, інтернет не потрібен.

## Де зберігаються дані

Усе лежить у **IndexedDB цього браузера** — задачі, ночі й самі фото. Нічого
не йде на сервер, бо сервера немає.

Наслідки:

- пристрої **не синхронізуються** — для перенесення є «Зберегти копію» /
  «Відновити з копії» в налаштуваннях (шестерня у шапці);
- очищення даних сайту в браузері видалить записи, тому час від часу роби копію;
- на iOS застосунок з іконки має окреме сховище від Safari — це не помилка.

Копія — це один JSON-файл. Фото в ньому лежать усередині, тому файл виходить
чималий; є окрема кнопка **«Копія без фото»** для швидкого перенесення самих
задач і сну. Відновлення **додає** записи до наявних, а не затирає їх.

## Запустити локально

Потрібен звичайний http-сервер: IndexedDB і service worker не працюють через
`file://`. Найпростіше:

```bash
python -m http.server 8788
```

І відкрити <http://127.0.0.1:8788>.

## Локальний хаб із Telegram-ботом — тека `local/`

GitHub Pages роздає лише статику, тому бот і запити до Claude живуть окремо —
у теці [`local/`](local/README.md). Це та сама трійка модулів, але на
Python + SQLite:

- Telegram-бот приймає фото їжі однією дією і сам питає тег;
- він же шле нагадування про відбій, навіть коли застосунок закритий;
- з ключем Anthropic тег підказує Claude, лишається підтвердити.

Дві половини не синхронізуються наживо, але між ними є місток: локальний хаб
віддає **копію у форматі веб-версії** (кнопка «Копія для телефона» в його
налаштуваннях або `GET /api/backup`), а веб-версія читає її через «Відновити
з копії». Так можна вести облік удома з ботом, а на телефоні дивитись графіки.

## Що всередині

```
index.html    розмітка: шапка, чотири вкладки, діалоги
styles.css    теми Latte і Mocha, сітка карток, адаптив
store.js      IndexedDB + уся логіка: стріки, ночі, теги, копії
app.js        малювання, графіки, події
sw.js         офлайн-кеш
manifest.webmanifest, icons/    встановлення на телефон
local/        необов'язковий Python-хаб із ботом
```

Графіки намальовані власним SVG — без бібліотек, працюють офлайн і беруть
кольори з теми.

## Оновити застосунок після змін

Сайт збирається з гілки `gh-pages`, тому оновлювати треба обидві:

```bash
git add -A
git commit -m "Оновлення"
git push origin main main:gh-pages
```

Якщо змінював `index.html`, `app.js`, `store.js` або `styles.css` — підніми
версію кешу в `sw.js` (`hub-v1` → `hub-v2`), щоб телефон підтягнув нову версію.

## Перевірка логіки

У `local/` лежить самоперевірка тієї самої логіки на Python:

```bash
local\.venv\Scripts\python local\tools\selftest.py
```

Обидві реалізації — Python і JS — рахують стріки, ночі й теги однаково: копія,
знята з локального хабу, дає у веб-версії ті самі числа.
